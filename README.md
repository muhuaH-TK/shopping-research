# Shopping Research · 购物研究与比较

[中文](README.md) | [English](README.en.md)

**版本：v1.3.0 · 试用版** · [版本变更](CHANGELOG.md) · [验证范围](VALIDATION.md)

面向消费者购买决策的 Codex 技能。根据用途、预算和硬条件研究商品，核对质量、安全、价格、口碑、长期成本和企业情况，交付具体版本、购买渠道、主要取舍及证据缺口。

技能入口为 [skills/shopping-research/SKILL.md](skills/shopping-research/SKILL.md)。技能本体目前使用中文指令；运行时的提问、选项、解释和报告跟随用户当前的交流语言，用户明确指定输出语言时优先采用。

## 主要功能

- 每个独立需求默认深入比较 3—5 个有实质差异的一般商品候选，先检查解决路径，再比较品牌、配置和价格；数量不足不凑，重要新方案可以继续扩展。
- 开放发现品牌与购买渠道，支持一个、多个或不限国家／地区的购物市场，不默认中国市场。
- 对应具体型号、市场版本、卖家、规格和批次核查证据；标准、抽检、召回和检测结论注明适用范围。
- 区分商品页公开价、条件券后价、已复现结算价及历史／聚合参考价；未知费用不填零，公开报价不冒充确定到手价。
- 每款前置有依据的分数及其性质、购买状态、购买入口和优惠领取信息，再给完整的 12 项说明。
- 相关食品额外研究并独立展示助农产品，继续追查来源关系及跨平台购买链接。

## 购物市场、隐私与语言

需要澄清研究范围时，技能采用以下问法，并按当前交流语言表达：

> 这次希望主要查看哪个国家或地区的购物渠道？例如中国大陆、日本、美国等，可以指定一个或多个，也可以不限。
>
> 是否同时考虑跨境购买渠道？

这里选择的是本次研究市场。技能不询问收货地、所在地或具体地址，也不从设备、账号等信息推断位置；所选市场不代表用户所在地、品牌国别或交流语言。已经回答的内容直接使用，未回答时保持渠道开放并继续可独立完成的研究。

配送范围、运税和地区适用性按公开条件核查；无法确认时说明条件和待核项，不承诺对用户确定可送达。保留原币价，有明确预算币种或指定币种时再并列相应换算。

## 每款保留的 12 项说明

| 项目 | 主要内容 |
|---|---|
| 需求适配 | 对本次用途和硬条件的匹配程度 |
| 实际价格与价值 | 同版报价、价格性质、必要条件及有效收益 |
| 优点 | 有依据的实际优势 |
| 缺点与取舍 | 已知问题、使用负担和选择代价 |
| 质量与可靠性 | 实际性能、耐久及证据覆盖范围 |
| 安全与合规 | 相关风险、适用要求及已核／待核结果 |
| 真实口碑 | 可归属的评价、长期反馈及商家回应 |
| 长期成本 | 耗材、维修、订阅、配件及相关使用成本 |
| 售后 | 保修、退换、服务和可维修条件 |
| 研发与营销 | 可核技术投入、成果及宣传依据 |
| 劳工福利 | 可归属主体的实际用工、待遇、争议及补救 |
| 条件结论 | 适合谁、当前购买状态和改变结论的条件 |

这些是独立说明视角，不是 12 项重复加权。具体指标按品类适配，未知保持未知。

## 一般商品评分与购买状态

默认七项权重合计 100：

| 维度 | 权重 |
|---|---:|
| 质量与可靠性 | 35 |
| 需求适配 | 20 |
| 实际价格与价值 | 15 |
| 长期成本 | 10 |
| 售后与可维修性 | 10 |
| 研发与营销附加项 | 5 |
| 劳工福利附加项 | 5 |

权重在评分前声明，可按用户要求调整并对候选统一应用。区分实证加权综合分、部分分和主观推荐分；证据不足不补分、不放大剩余权重，核心证据不可比时不强排。负面事实与单纯缺证分开，同一问题不重复扣分。安全要求及硬条件独立设门槛，高分不能抵消已证实不满足的关键要求。

分数旁同时标明以下购买状态之一：

- **可进入购买决策**：版本、核心需求、硬条件、关键安全、报价及必要交易条件已有足够依据。
- **仅适合优先核验**：候选可能有价值，但仍有会改变选择的关键缺口。
- **证据不足，暂不排序**：不足以形成有意义的选择判断或可比顺序。
- **不符合本次购买条件／排除购买**：已确认不满足本次硬条件，或关键安全要求已证实不满足。

允许结论为“当前没有足够依据推荐购买”。公开整份检测报告缺失不自动等于不安全或不合格；判断落到具体型号、项目、风险和证据范围。

## 独立助农板块

研究相关食品时，主动寻找农户、家庭农场、合作社及与农业生产者关系明确的商户，覆盖生鲜、粮豆干货和加工农产品。适度深挖线索、横向扩展候选，发现具体产品后继续到相关多个平台及销售渠道追查实际购买链接。

卖家身份、产品来源和助农关系分别标明核实程度。“助农”板块名称不代表官方认证，也不保证农户实际收益。笼统产地、乡村画面或助农口号只作线索。

助农产品额外单列，不与一般商品比对、评分或排名，不占一般商品候选名额，不设固定数量，默认不套一般综合总分。完整 12 项、安全门槛、购买状态和证据要求继续保留；同类对象可作有依据的条件比较。

## 安装

### 底稿、复核与默认留档

每次交付默认保存完整报告、[研究底稿/证据索引](skills/shopping-research/references/research-workbook.md)、复核记录及运行版本/验收记录，并核对实际保存结果。优先由分开上下文的代理先读需求和原始证据、再对照草稿；不可用时如实披露同代理复核。重要分歧须解决或保留购买限制，不能平均分掩盖。

按[复核与留档规则](skills/shopping-research/references/review-and-archive.md)使用本项目或当前任务可写的输出目录；保存失败明确交代成功范围，不把聊天展示当作文件已经保存。重要字段分别标注本轮复核、沿用、失效或待核，一个报价更新不代表其他资料同步更新。

[品类审查卡](skills/shopping-research/references/category-cards.md)提供枕头、洗护、电器和骑行用品的查证重点与证据边界，不是品牌白名单、认证配额或已验证商品清单。

### 安装方式

在支持 Codex 技能的环境中，可使用内置的 `$skill-installer`，提出：

```text
请从 https://github.com/muhuaH-TK/shopping-research 安装 skills/shopping-research 技能。
```

也可将本仓库的 `skills/shopping-research` 整个目录复制到客户端配置的个人技能目录。保持目录名、`SKILL.md`、`agents` 和 `references` 的相对结构，避免只复制入口文件。已有同名技能时，先检查差异并备份。安装后在下一轮对话中调用。

## 使用示例

```text
使用 $shopping-research，帮我比较适合长时间办公的可调高度枕头。
预算为 100 美元，重点查看美国和日本的购物渠道，也考虑跨境购买。
请用中文输出。
```

也可以给出已有候选、商品链接、截图或旧报告，要求继续研究或更新；技能应保留原材料的日期和已核范围，不把文字重排当作重新核价。

## 能力与行动边界

- 本仓库提供研究指令及参考规则，实际联网、浏览和文件操作依赖所在客户端的可用工具与授权；不自动安装依赖，也不保证读取所有平台。
- 不绕过登录、验证码或访问控制，不默认联系卖家、加入私域群、注册账号、领取优惠或下单。需要额外行动时遵从当前授权边界。
- 单页失败后按原因做合理替代读取，缺关键资料时先研究其他候选；完成定向补查后可有据结束，不要求穷尽全网。
- 新购物研究开始时，仅将已知购物输出中严格超过 30 天且无保留例外的项目列为清理候选；用户确认具体清单后才移入回收站。没有定时或自动删除机制，失败时保留文件。
- 规则和文件检查不等于真实商城、多语言对话或结算流程已通过端到端实测。结果应明确本次实际核实内容和剩余限制。
