# 可复用品类审查卡

按本次用途读取相关卡片，用它确定关键性能、版本差异和取证顺序；卡片不是全部商品通用的准入清单，也不替代逐款12项研究、[安全审查](health-safety-review.md)、[证据规则](evidence-rules.md)与[购买决策标准](purchase-decision.md)。不按价格高低缩减研究模块；具体指标依商品和实际风险选取，不能为了填卡增加无关认证或检测要求。

先核准确SKU及目标购物市场，再将卡片中的重要判断写入[统一研究底稿](research-workbook.md)。每条留下适用对象、实际读取内容、支持与反证、缺口及购买影响。以下是审查方法，不表示某款商品已验证，也不把既有报告的旧价、旧测试或个人需求移作当前事实。电器卡同样只是方法整理，不宣称已完成电器真实选购验证。

## 枕头

| 审查项 | 需要落实的判断 |
|---|---|
| 关键性能 | 依据已知睡姿、支撑偏好和床垫条件，看受压后的承托、高低侧/可调结构、回弹与下陷、翻身空间、透湿热感、噪声及清洗负担。标称高度不直接等于使用时高度；“越高、越硬”不能单独推出更适合。体型、肩颈间距或睡姿未知时给条件分析，不编个人测量值。 |
| 常见版本差异 | 同名不同高度、尺寸、填充量/材料、内芯结构、外套、地区货号和洗护方式分别核；“四季版”“升级版”及相近型号不合并。外套检测不自动覆盖内芯，原料证明不自动覆盖成品。 |
| 决定性风险 | 核与实际材料、接触及人群相关的释放/接触风险、填料外漏、结构破损和洗护限制。成人枕的结果不能外推婴幼儿适用；电热、磁疗等附加功能另按其具体风险和宣传依据审查。不能由异味或材料名称单独认定有害，也不能把舒适度研究写成治疗颈椎疾病的证据。 |
| 优先资料 | 准确货号的官网尺寸、材质和洗护说明；对应部位的标签/报告；有方法说明的同货号独立测试及长期反馈。可从[香港消委会枕头测试方法](https://www.consumer.org.hk/tc/article/593-pillows/593-pillows-test-items-and-results)学习如何区分承托、耐用和舒适测试，但须另核样品市场、购样日期、体型、床垫和测试条件。 |
| 证据怎样支持结论 | 官网页可支持尺寸、材质宣称和洗护适配推断；对应实测才支持所测条件下的承托或形变表现，测试星级不换算成寿命年数。个人试用与退换条件可处理舒适/高度的不确定性，不能代替关键安全证据。只有外套材料结果时保留该局部结论；如确有影响购买的内芯关键风险未明，指出具体缺口，不笼统写“无整份报告，整款安全待核”。 |

## 洗护：日常洗发、沐浴及相关清洁产品

| 审查项 | 需要落实的判断 |
|---|---|
| 关键性能 | 围绕清洁、冲洗、使用后干涩/打结/紧绷、油腻残留、香味耐受、用量与包装浪费核表现。头皮、发丝和身体皮肤分别判断；身体偏油不能直接推出油性头皮。日常清洁、去屑等特定功效和疾病治疗声称分开，不为普通需求添加未提出的功效目标。 |
| 常见版本差异 | 核完整名称、市场、配方/成分表、容量、泵装/补充装、香型、制造/责任主体及可取得的批次。不同地区同系列或包装近似不代表同配方；旧版评价和其他香型资料只在能说明可比范围时采用。以相同有效使用量或明确情景核长期成本，不把不同浓度都按每毫升价格排优劣。 |
| 决定性风险 | 按实际接触方式核标签警示、已知成分限制和与本次用途相关的刺激/致敏、眼部接触及使用频次问题；只使用已知个人限制，不索取无关病史。成分出现、配方“天然/无添加”、备案存在或一次个人无不适都不单独证明整体安全或耐受；浓度、配方组合及接触条件未明时不编风险发生率。 |
| 优先资料 | 当前版本包装正背标、品牌完整成分及使用说明、目标市场相应的注册/备案与抽检入口、同版功效研究、可归属的购买者长期反馈。研究中国大陆销售版本时，可从[国家药监局化妆品栏目](https://www.nmpa.gov.cn/hzhp/index.html)与[数据查询说明](https://datasearch.nmpa.gov.cn/datasearch/search-help.html)定位信息；其他市场另查对应主管机关和实际销售路径，不机械套用同一登记要求。 |
| 证据怎样支持结论 | 标签支持该版本的明示配方与用法，登记信息支持实际查到的主体/身份及状态；均不自动证明清洁更强、去屑有效或对个人不会刺激。成品功效资料须对齐对象、方法、用量、对照及结果；原料研究仅作机制线索。清洁与冲洗反馈可支持带样本边界的体验判断，不能由少量差评推算普遍过敏率。确有匹配版本的关键禁限用或抽检问题时处理相应门槛，其他未核资料按影响披露。 |

## 电器、电源与含电池设备

| 审查项 | 需要落实的判断 |
|---|---|
| 关键性能 | 先按用途定义实际输出与工况：例如加热效果、照明表现、噪声、有效续航、负载能力或充电兼容；再核持续运行、能耗、操作和维护负担。额定功率、容量、接口外形或峰值参数不直接证明实际效果、转换效率、协议兼容及耐用性。 |
| 常见版本差异 | 对齐完整型号后缀、销售市场、额定电压/频率、插头、适配器、充电协议、电池与固件、附件和保修身份。同名不同供电版本不混用；只有转接插头不能据此认定供电兼容。整机、裸机、改装套件和另购电源的实际交付范围分别核。 |
| 决定性风险 | 按结构和工况核触电、过温/火灾、漏液/进水、压力/烫伤、机械运动及电池充放电风险；关注保护机制、安装散热条件、匹配充电器与可预见磨损。先查实际适用的必备要求和认证目录，不把某项标识设成所有电器的共同门槛，也不用管理体系证书代替产品符合性。 |
| 优先资料 | 厂商对应型号的说明书、铭牌、兼容/安装清单与维修政策；目标市场适用要求；发证机构公开验真入口及可用的监管查询；同版性能/异常工况测试、抽检召回与补救。研究中国标准可从[全国标准信息公共服务平台](https://std.samr.gov.cn/)和[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/)定位；认证入口可从[国家认监委服务栏目](https://www.cnca.gov.cn/hlwfw/)查找，仍须核具体发证机构、证书对象、状态及系统覆盖。 |
| 证据怎样支持结论 | 铭牌与说明书支持明示供电和安装条件；有效且匹配范围的符合证据支持相应安全项目，所测工况的性能报告支持对应表现。二者不互相代替，单一保护元件不证明整机异常工况安全，保修年限不等于寿命。无公开整份报告时保留已核证书/抽检等结果；只有关键要求实质未明才限制对应购买结论，已证实关键不满足则排除。维修/更换费用和耗电按有来源的使用情景核算，缺项不编完整持有成本。 |

## 骑行用品：整车、助力系统及防护装备

| 审查项 | 需要落实的判断 |
|---|---|
| 关键性能 | 整车看具体用途下的骑行/助力响应、足够的可用续航、制动与控制、尺寸适配、搬运停放及维护；头盔等装备看对应活动的防护范围、佩戴调节、稳定性、视听影响和通风负担。标称里程、低重量或昂贵材料不直接证明真实续航、耐久或防护更好。 |
| 常见版本差异 | 普通自行车、助力整车、电动两轮车及改装套件先分清交付形态和目标市场分类；核年份、车架尺寸、制动配置、轮胎、电池、充电器、固件/限速状态及保修。头盔按用途类别、尺码、结构、认证型号与生产/使用记录对齐；同系列不同防护用途不能互换证据。 |
| 决定性风险 | 按实际对象查制动、车架/前叉/轮组和连接失效、载荷、轮胎及装配兼容；带电系统再核电池充电与热风险。防护装备核冲击、固定与佩戴等适用项目及更换条件。研究道路用途时另核目标市场车型/通行要求，不以“能骑”认定可合法用于所有道路，也不推断用户所在地。不能让用户以试骑或摔落测试验证安全底线。 |
| 优先资料 | 原厂准确版本说明书、整备重量与载荷、装配/兼容说明、维护和易损件清单；目标市场的标准、必要符合证据及型号对应查询；有完整条件的实骑/实验室测试与售后反馈。召回按市场查主管机关，例如[美国CPSC召回入口](https://www.cpsc.gov/Recalls)仅用于其实际覆盖市场和产品，不代替其他地区核查；未检出召回不作安全通过证据。 |
| 证据怎样支持结论 | 工况明确的实骑可支持该载荷、路线、助力档位等条件下的里程与体验，不从部分耗电线性外推满电续航。结构/制动或头盔测试只支持对应版本、项目和条件；防护合格不保证任何事故无伤。合规与关键安全证据满足、用途和交易条件清楚时，可按决策标准进入购买判断；核心风险或必备要求实质未明时指明缺口。改装后的结果不自动覆盖原厂车或另一组合，不能用高性能抵消不兼容或已证实的关键失效。 |

## 使用卡片后的核对

将“厂商明示”“同版实测”“可归属长期反馈”“分析推断”和“未知”分别记录。资料入口存在、标准现行、检测机构有资质或同系列曾测试，都不等于当前候选的项目已经通过；报告首页、摘要、原始全文及查询结果也分别说明。入口失效或返回限制时按证据规则实际尝试合理替代，仍未取得就保留缺口，不把入口写成永久可用。

四类卡片均须回到相同决策链：核心用途与硬条件是否满足、关键安全项目状态如何、当前同版报价及必要费用/配送/售后是否足够支持购买。不同品牌和知名度使用相同要求；资料少本身不扣产品表现分，已有负面与其实际后果按[评分规则](scoring.md)归属一次。保留完整12项说明，不能用填完卡片代替企业、价格、口碑、长期成本和交易条件研究。
