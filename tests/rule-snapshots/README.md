# 评分运行的规则快照

这里保存各次验收实际使用的运行文本，扩展名追加`.txt`，不会作为另一个可发现技能加载。它们仅用于复现和比较，不是默认安装入口。

[r1清单](r1/manifest.json)列出原相对路径、对应快照路径和原文件SHA256；逐个移除追加的`.txt`扩展名并恢复原目录，即可重建当轮运行输入。所有文件的路径→SHA256字典按键排序、以无空格JSON序列化为UTF-8，再作SHA256，即得到runtime_hash。固定原始材料另在fixtures，运行结果中分别记录输入和规则哈希。

后续规则修订保留原快照、原始评分和失败记录。共享评分口径卡若参与复测，也单独冻结并记录哈希，不向评者提供oracle或前次候选分数。原始商品记录、用户验收容差及安全门槛不能为取得通过而倒改。
