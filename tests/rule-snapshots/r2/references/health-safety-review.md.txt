# 所有品类的健康与生命安全审查

适用于任何商品中与身体健康、生命安全有关的内容。先识别风险，再选择相关标准和证据，不仅审查食品，也不把所有商品套进同一认证或检测清单。食品另读[食品质量与营养审查](food-quality-review.md)。

## 确定实际风险与审查范围

从用途、接触部位/时长、能量或负载、使用环境、目标人群和可预见失效切入；同时看正常使用、老化/磨损、充电储存、清洁维护及合理可预见误用。区分危险后果的严重性、暴露条件和有证据支持的发生情况，不凭印象编事故概率。

涉及儿童、老人、身体限制或特定工况时，用已知事实判断适用性；确需补充的年龄/体重/尺寸/电压等集中简问，不泛问医疗或家庭隐私。用户没提事故不代表无需审查，未查到事故也不证明安全。

以下只是发现相关指标的示例，不是所有商品的强制清单：

| 品类/接触情景 | 可影响健康或生命安全的审查方向 |
|---|---|
| 电器、电源、电池、充电设备 | 触电、绝缘/接地、漏电、过流/过温、热失控与火灾；额定电压、功率、接口和充电兼容；异常工况保护 |
| 自行车、助力车、头盔和防护用品 | 制动/结构及载荷、轮胎与关键连接、冲击吸收与佩戴适配、电池充电；故障后果和维修/更换要求 |
| 家具、运动器材、梯具、承重用品 | 稳定性、倾倒、承载/疲劳、连接强度、夹伤/跌落、适用体重与安装锚固；相关材料释放或接触风险 |
| 洗护、化妆品、清洁剂及长期皮肤接触物 | 配方/材料、刺激致敏、有害物质、眼口/吸入接触、浓度与使用方法、适用人群；不以“天然/无添加”替代证据 |
| 婴童用品、玩具、磁性/小部件产品 | 窒息、误吞、绳带/夹困、锐边、磁体、电池和化学暴露；年龄分级、结构和监护限制 |
| 厨具、食品接触材料、压力/加热设备 | 迁移/有害物质、耐温、压力、烫伤、密封与结构失效；材料、温度/介质和使用寿命条件 |
| 食品与营养补充品 | 配料/过敏原、营养真实性、污染物/微生物、储存有效期及健康声称，按食品专项细化 |

不根据单条评价、材质名称或理论可能性认定存在实际缺陷；列出为何该风险与此商品和用户工况相关，再找有针对性的证据。

## 把风险对应到标准与具体产品

1. **定对象。** 核型号、版本、批次、制造商、销售/使用国家地区、额定参数和用途；认证、测试、旧型号或其他地区版本都须逐项匹配。
2. **定要求。** 从监管机关、官方标准平台或适当的原始来源核现行及过渡期规定，记录编号、名称、版本/实施日期、范围及适用理由。区分强制要求、推荐标准、企业标准及自愿认证；不一概要求所有商品同一认证，不把境外合规自动等同目的地适用。
3. **核证据。** 按下节区分标准、企业声明/自检、委托检测、认证与机构资质、监管抽检；核证据真实性、覆盖对象、部位、项目、结果及适用限值/工况。商家声明、标识或报告按钮不能冒充已读检测结果；自营/进口、知名品牌及高价也不能代替具体证据。
4. **核表现与反证。** 查相关独立测试、长期反馈、官方抽检、事故/召回及补救；对齐型号、批次、环境、使用时长和问题。不扩大历史召回到全部产品，也不因未搜到负面奖励安全分。
5. **解释边界。** 合格证据覆盖哪些风险/工况，哪些没覆盖，是否有安装、维护、寿命、替换或个人适配前提。单次通过不保证所有批次或所有使用方式，说明具体覆盖范围，不作零风险承诺。

## 区分证据及其覆盖范围

| 证据类型 | 可支持的判断 | 不能据此推出 |
|---|---|---|
| 法规、标准文件及执行标准编号 | 适用义务、指标、方法和企业明示采用的要求 | 某个产品已做检测、实测合格或全部批次符合 |
| 企业声明、标签、合格证明与自检记录 | 企业明示内容及已核到的内部质量检查；分别标明仅有声明还是读到记录 | 自动等于独立第三方验证，或仅凭标准编号就确认实测结果 |
| 委托检测报告 | 所送样品、部位、方法及项目的检测结果 | 商家送样等于独立抽样；原料、外套或其他型号报告覆盖整件成品、内芯或全部SKU |
| 产品认证及认证证书 | 认证方案、对象、有效期和范围内的符合性评价 | 覆盖证书外型号/项目，或等于全部风险均已验证；管理体系认证也不等于产品认证 |
| 检测机构资质或认可 | 机构在有效认定/认可范围内的相应检测能力 | CMA、CNAS等机构资质或认可标识就是产品认证、该报告全项目合格或产品功效获证实 |
| 监管抽检、召回及独立测试 | 可归属具体对象、批次及所检项目的结果或缺陷事实 | 未被抽中等于合格、一次合格覆盖全部批次，或其他产品问题可以套到当前候选 |

标准文件与产品检测报告分别核查。未取得公开整份报告，只能说明在已查渠道中未取得对应证据，不自动等于未检测、不合格或整款安全门槛待核；也不能反向假定已经检测合格。报告可能仅由委托方持有、只有部分项目公开，或与当前型号/部位不匹配；未核到原因时不替企业断言。已取得的可信证书、抽检或其他原始证据可在其实际覆盖范围内采用，不因缺另一份公开报告一并作废。

取得报告或证书后，按可得内容核对：报告/证书编号、出具机构及认定/认可范围和有效状态、委托人、签发/检测日期、样品名称及型号/版本/批次、送样还是抽样及实施主体、检测部位/材料、标准版本、方法/工况、项目、限值、实测结果和检出/定量限（适用时）。注明读到全文还是节选，不能用首页、二维码或机构标识补出未读结果。通过当次可用的监管查询或机构官方公开验真渠道核查真实性，核对查询返回信息与文件内容，查到编号不等于确认全部内容，未查到也须先核查询范围、更新时间及渠道限制。不要把某次查询网址、开放状态或上传规则写成永久事实。

普通商品不一律设为“逐型号、逐批次必须向公众公开完整第三方报告”。是否必须检验、由谁检验、频次、合格证明/认证/披露义务，须当次从适用地区和品类的权威要求核实；推荐核验材料与法定义务分别说明。

默认工作流只使用公开资料和公开验真入口，不把联系检测机构列为研究步骤或完成前提。公开核查仍不足时记录具体缺口、影响及可用替代证据；以后用户明确要求对外联系时，再作为单独任务处理。

按“型号/版本/批次 × 材料或部位 × 项目/工况”记录证据状态：

- **已核符合（限范围）**：可核证据支持该对象及所列项目符合对应要求，注明实测值或认证/抽检结论及限制；不外推未检项目。
- **未核实**：未取得或未能匹配相应证据，列清缺口与已做补查；不把缺证直接写成实际缺陷。
- **已证实不满足**：可信证据确认不满足适用要求，写明事实、标准和涉及范围。
- **不适用**：说明对象、用途或材料为何不落入该项要求；不能以境外对照或不适用项凑成安全通过。

## 中国及其他国家、地区标准的明示

凡用于判断或比较的标准都逐项列明，不能只用“国标”“欧标”“美标”“国际认证”概括；标准、法规、认证方案及合格标识分别识别，不把机构名称或标识当标准编号。

除实际适用要求外，按品类主动寻找有实质比较价值的其他国家/地区或国际标准作对照，说明为何选用及指标可比性；未取得或没有合理对照时写清，不为凑国家数量机械套用无关标准。

| 必填内容 | 如何说明 |
|---|---|
| 国家/地区及标准体系 | 中国、具体其他国家/地区或国际体系，注明与销售/使用地及购买路径的关系 |
| 编号、名称与版本 | 完整编号/年份和正式名称；修订版、替代关系、现行/过渡期状态及实施日期，尚未核到则注明 |
| 性质与适用关系 | 强制要求、推荐标准、企业标准或自愿方案；本商品实际适用/通过其他要求引用/仅作质量对照及理由 |
| 关键要求与比较口径 | 相关条款/测试项目、限值或性能要求、单位和试验条件；不相关项目不强行套用 |
| 同版证据与结果 | 型号/批次、报告日期/来源、实际值、符合/不符合/未核及其范围，不拿其他版本替代 |
| 官方来源与读取范围 | 标准发布或监管/认可机构链接及读取日期；只读摘要、目录、节选或全文分别说明 |

交付可将长表附后，但每款正文要保留影响购买的标准名称/编号、适用关系和具体问题。目标市场适用要求与其他市场的比较标准分组，适用项不足不得由对照项“通过”替代。比较不同地区阈值或声称某标准更严，须先对齐产品类别、指标、方法、单位和条件；不能按国家名气排质量。没有取得规范或符合证据时明确未核，不编编号、阈值和合规结论。

## 形成可审查的结论

逐款底稿采用“风险与后果｜适用要求及依据｜同版证据和关键结果｜使用/人群限制｜已做补查与剩余缺口｜门槛及评分影响”。只列标准名、贴认证图或套写“报告待核”，不算完成严格审查。先逐项记录证据状态，再判断哪些项目构成整款的实质安全门槛。

- 安全门槛分别标通过、待核或不满足，明确其风险、适用要求和证据范围；不得仅因缺公开整份报告就将整款列为待核。已经证实不符合关键安全要求的候选，不因便宜、营养/性能高或推荐分高而保留为可买结论。
- 只有关键健康/生命风险的符合证据，或适用的法定必备要求的满足情况实质未明，才将对应门槛保留待核并限制确定购买结论；说明可能的危害、具体缺什么，以及现有替代证据为何不足。这一限制不以已经发现事故、差评或不合格为前提；不能把未检出负面当作关键门槛通过。其他未核项目按范围披露，不自动封锁整款推荐。关键安全门槛不能被企业口头保证、低价或其他项目合格替代，也不能让用户靠自行试用验证触电、防护、承重等安全底线。
- 实证质量分是否N/A取决于支持该评分所必需的质量资料是否不足，并指出受影响维度；缺一份公开报告不自动清空其他已核质量证据。有意义的暂定推荐分可表示核验优先级，必须标明条件，不包装成确定购买保证。
- 质量分综合性能/材料真实性、工况稳定性、失效与长期证据；安全达标作为门槛不重复奖励。用户适配、费用、售后各按具体理由计分一次。
- 聊天的质量与安全两项分别给关键数据、结论、适用限制及缺口，长底稿附后；没有进行实际检索/证书核验/检测阅读时如实说未完成，不能把建立规则写成已审查产品。
- 已核安全/合规问题写清违反或不满足的具体要求、实测/事实、伤害路径、涉及对象、补救及扣分归属；可信投诉与单纯缺证另标，按[扣分规则](scoring.md)处理，安全门槛和数值扣分不重复。不能把“安全有问题”作为没有细节的结论。
- 范围随风险收束：完成适用指标的针对性查证后停止，不无限追查无关危害；缺关键证据时可改选证据可核的候选或保留核验条件，不凭空补结论。
