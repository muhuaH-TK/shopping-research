# 固定材料与评分一致性验收

本目录的商品、主体、记录、价格和交易条件**全部虚构**，只用于测试推理；不是现实商品案例、检测报告、合规证明或购买建议。`T-`开头的条件是题设中的验收约定，不是现实国家或行业标准。真实购物研究、个人需求与真实对照结果不在本目录公开。

## 文件与盲评边界

- `fixtures/F1.json`—`F5.json`：五组完整、冻结的需求与原始记录。评测者每次只收到其中一组、候选版技能及输出要求。
- `result.schema.json`：评分底稿的机器可读结构。缺资料使用`null`，理由解释N/A；不得借schema自动填分。
- `oracle.json`：供验收者使用的不变项、计算与判定要求。**不得交给被评代理，也不提前给其旧得分、排序、疑似错误或预期答案。**
- `runs/`（实际运行后才产生）：保留真实输出和运行元数据。没有结果文件，不表示测试已完成或已通过。
- `check_results.py`：使用Python标准库检查实际输出的结构、算式、原分母及跨运行漂移；不替代独立语义复核，不自动运行评者或填造结果。
- `rounds.json`与[规则快照](rule-snapshots/README.md)：保留当轮完整规则版本、输入哈希及配置的实际可知范围，旧规则不会因当前技能更新而丢失。

固定材料不是商品全篇交付测试。每次只需提交分项、锚点、证据ID、计算、扣分事件归属、安全门槛、购买状态和条件顺序，不需重复生成完整12项报告。日常购物研究的深度与交付要求保持原样。

## 本轮执行协议

每组在同样执行配置下用两个干净上下文分别评分，再交另一独立代理评分一次；共5组×3次＝15份底稿。记录候选技能版本及内容哈希、输入哈希、执行配置、运行ID和日期。不得继承此前评分或复核结论；不联网补充虚构对象的资料。若相同配置无法保证，应注明差异，不把结果称作单一变量的重复试验。

先校验每份底稿的规则与计算，再比较三次结果：

1. 同一可评分分项的最大分与最小分之差不超过1／10；完整七项综合分之差不超过5／100。
2. 安全门槛、购买状态、关键反证及扣分去重必须一致，不能用平均分掩盖分歧。任何一次漏掉关键反证、把未知补成分数或让高分抵消门槛，相关题即未通过。
3. N/A与实评分出现差异，也属于实质范围分歧，应单独复核；不能只计算数值分差后略过。
4. 部分分保留原项目、原分母。相同分母但项目不同也不能混排；不把部分分换算成百分制。
5. 接近候选允许合理名次差异；若改变实际购买建议，必须解释并复核。不得把本测试的1分／5分漂移容差变成日常的“相近候选”阈值。

首轮之后最多进行两轮针对性修订与复测，保留原始失败记录，只重测受影响项和必要关联项。不得删题、替换失败输出、倒改原始材料或改验收口径来凑通过。若发现题设本身有错误，另立修订版并说明变更，原版本与原结果仍保留。

这是小规模、特定材料及执行配置下的初步一致性检查。即使全部通过，也不能宣称评分具有统计普遍稳定性、适用于所有模型或已证明真实购买能力。真实场景另按“流程执行合格”和“购买证据闭合”分别验收。

运行已经存在的首轮底稿检查：

```text
python tests/check_results.py --round r1
```

文件缺失将记为未观察/未完成；程序不会生成缺失评分。机器检查后的证据引用、关键反证、扣分去重和购买取舍仍需语义复核，不能只看退出码。后续轮次保留独立目录及规则/输入哈希，旧失败结果不覆盖。

## 首轮与校准复测的区别

r1十五份实际结果及[语义审查](runs/r1/semantic-review.md)完整保留；该轮自定锚点出现分项、总分或状态分歧，未通过。r2读取相同原始记录、修订规则和[共享口径卡](calibration/r2/README.md)，用于检查已知材料按共同尺度执行；它是事后标定复测，不是新题盲测，不能将其通过表述成自由评分或新材料泛化已稳定。两轮输入差别及哈希在rounds.json分别记载。

r2十五份数值一致，但语义审查发现一处F2扣分理由的比较方向写反；原件不改。最后r3只覆盖受影响的F2三份新上下文，沿用相同事实/规则/共享卡，增加保存后逐字核对原数值、比较基准、百分比分母及方向/单位的步骤。轮次清单明确选择范围；r3通过也不表示重新跑了其他四组。不会为凑通过无限换题或继续第四轮。

`rounds.json`中的r3任务提示词原件哈希用于维护者内部追溯；原件含本地输出路径，仅私有留存。公开流程摘要见本节，公开读者不能据此重算原提示词哈希。输入、规则、共享卡与实际评分输出均可独立核对。

## 五组材料的覆盖范围

| ID | 主要覆盖 |
|---|---|
| F1 | 核心表现证据不对称、未知不能获得优势、报告未完整公开不自动封锁 |
| F2 | 同一事件主要归属、独立后果可另计、口碑不另加权 |
| F3 | 不同部分分分母、相同分母不同项目、未知不归一化 |
| F4 | 关键安全待核、已证实不满足、局部有效证据覆盖、状态不由高分抵消 |
| F5 | 七项可评的完整计算、核心适配与企业附加项的取舍、近分条件顺序 |

评测者不必阅读本覆盖表；它用于维护者检查测试集是否遗漏必要情形。
