# 食品质量、健康与营养的具体审查

这是[健康与生命安全审查](health-safety-review.md)之下的食品专项，用于食品、蛋白粉和营养补充品的选购与评分；不是诊疗或为所有食品设置同一配方。只审查与类别、销售市场、商品版本、已知交易路径和用户用途相关的事项，不要求用户填无关的完整病史，也不询问收货地；地区适用性未明时分条件说明，保留安全门槛。其他产品的健康/生命安全同样须按总则严格审查。

相关食品研究还须按[助农产品独立板块](farm-support-products.md)主动寻找候选。助农产品保留本专项的完整研究和安全底线，独立展示，不与一般商品比对、评分或排名；下文涉及统一总分、企业资料及商城格式的要求按该专项适配。

## 先确认对象与适用规范

核准确名称、口味、容量、销售市场、配方版本、生产商、生产/有效日期及能取得的批号。食品、运动营养食品、膳食补充剂、保健食品及特殊医学用途产品等身份不可混同；没有蓝帽不能单独判普通食品差，也不把外国销售资质当中国批准。

农产品按实际形态核生产者与卖家、产地、品种、分级、净重及可取得的采收/加工时间、批次和储运信息；原样生鲜、粮豆与加工食品分别确认适用要求，不把品牌、工厂、配方、配料表或营养标签一律设为所有原样农产品的入场条件，也不据此豁免实际适用的法定要求。逐款分开记录卖家身份、产品来源与助农关系；材料属于商家自述、已独立核实或未知时如实标注。具体生产者或供货关系尚不能建立时只保留查证线索，单有厂名、笼统产地或“助农”口号不够。

检索主管机关、官方标准平台、官方召回/抽检和原始报告，确认现行及过渡期规定的编号、名称、版本/实施时间、产品类别、适用地区和要求。按目标市场的实际购买路径区分一般贸易、跨境零售或当地购买；例如研究中国大陆市场时区分大陆一般贸易、跨境零售或境外本地购买，其他市场按其对应路径核查，不能机械要求所有境外商品适用同一组中国标准。不要将国家/地区强制标准、推荐标准、企业标准、行业建议和自愿认证混称强制认证。

标准有效只证明规范状态；还要将具体产品/批次数据与其对应。网站出现“检测报告”按钮或认证标识不等于报告已读、项目合格或覆盖当前SKU。不得写未核实的标准编号、阈值及适用结论。

按[健康与生命安全审查的证据规则](health-safety-review.md#区分证据及其覆盖范围)，分别记录标准文件、企业声明/自检、委托检测、产品认证与机构资质、监管抽检。未取得公开整份报告不自动等于未检测、不合格或整款安全门槛待核，也不据此假定合格；按具体配方/口味/版本/批次及所检项目列“已核符合（限范围）／未核实／已证实不满足／不适用”。不得把全部食品预设为逐款逐批必须公开完整第三方报告，具体检验、合格证明、认证或披露义务须当次核适用的权威要求。

助农产品没有某项自愿认证不自动排除。有认证、合格证明或检测报告时分别核真伪、状态、主体、对应产品、有效期及覆盖范围，不能互相替代，也不自动证明卖家自产自销或农户实际获益。具体产品来源与助农关系仍须单独查证；认证名称或承诺文字不能代替本批次所检项目和储运判断。

## 逐款建立审查底稿

每项记录“审查事项｜适用要求/比较口径｜已核值或事实｜来源、日期及版本/批次｜结论与缺口”。不适用需说明原因，未知需指出已做的针对性补查及对推荐的影响。不能只填“待核”而没有具体检查。

| 审查方向 | 具体核查 | 结论边界 |
|---|---|---|
| 标签与身份 | 实际配料、营养表、份量、市场版本、制造主体、有效期、过敏原及必要警示 | 商家原图为标签宣称；旧口味/批次、转载图和用户录入库不能补成当前标签 |
| 农产品来源与批次 | 按相关性核生产者/供货关系、产地、品种、分级、净重、采收或加工日期及批次 | 具体自述是待核材料，不冒充独立核实；来源明确不等于助农获益已证实，不把其他产地或批次的结果移用 |
| 配料与蛋白来源 | 浓缩/分离/水解乳清、酪蛋白或动植物混合；添加量与成品蛋白比例、氨基酸/其他含氮成分 | 不把“100%乳清”或96%原料添加量读成成品100%或96%蛋白；混合来源不自动劣质，但不得冒充纯乳清。仅有含氮成分线索不足以认定掺假 |
| 营养参数 | 每100g及每份的能量、蛋白、脂肪/饱和脂肪、碳水/糖、钠；有依据时核氨基酸及亮氨酸 | kJ/kcal、粉重/蛋白重、糖/碳水分别处理；换算同量蛋白的热量、营养及费用。缺热量不推算为低卡，不做精确热量排名 |
| 健康与耐受 | 乳蛋白过敏与乳糖不耐受、已知用户限制、配料及添加剂的相关用量/依据、适宜人群和使用条件 | 分离/水解不自动无乳糖或防过敏；无蔗糖不等于无糖/低热量，合法甜味剂不因名称直接扣分，“零添加”不自动更健康 |
| 污染物与微生物 | 按类别核适用的重金属、其他相关污染物及微生物要求；实际检测项目、单位、限值与结果 | 不为所有食品硬套同一限量；核报告日期、样本、批次、方法和检出/定量限。未检出不等于含量绝对为零，一次合格不保证所有批次 |
| 检测与认证 | 实验室身份及能力范围、产品认证方案/对象、报告编号和验真结果、委托人、日期、样品型号/配方/批次、送样或抽样、检测对象/项目、标准版本及结果 | CMA/CNAS等机构资质或认可不是产品认证，也不等于全项目/全SKU合格；商家送检与独立抽检分别标，不以赞助测试冒充独立证据，部分报告不补成全项结果 |
| 抽检、召回与真实性 | 官方不合格/召回的具体产品、地区、日期、批次、问题及补救；授权渠道和可核追溯信息 | 不扩大到整品牌，也不以未检出负面证明安全；自营、进口或防伪码不能替代食品检测 |
| 储存与体验稳定性 | 密封、有效期、开封后要求、运输条件、溶解/口味和可归属同版的不适反馈 | 大桶、泡沫、结块或口感不能单独证明掺假/不安全；区分受潮变质线索与正常物理表现，不用个案计算发生率 |
| 宣传与目标适配 | “增肌/减脂/吸收率/提高免疫”等声称的原始依据、研究对象、剂量和结果 | 原料研究不自动证明成品有效；补蛋白与直接燃脂分开，群体结果不承诺个人效果；费用情景不是每日用量建议 |

只在同口味、同版本和可比检测条件下横比；助农产品仅在独立板块内部对同类、可比品种/等级/批次条件作比较，不与一般商品横比。先用适用于该食品形态的标签/追溯信息和规范建立基本判断，再定向补查批次检测及官方抽检/召回；无资料不假定合格或不合格。对未公开或无法访问的证据，记录具体项目、对象/批次缺口、替代尝试和现有证据能覆盖的范围，不承诺平台全部可读。证据验真沿用总则的当次渠道核查，不把查到编号等同全文已核，也不把查询无结果直接认定报告虚假。

## 评分与交付

以下分数规则适用于一般商品。助农产品默认不套一般商品综合总分，保留完整12项与购买状态，按专项作同类内部条件比较；已核实问题、可信负面和证据缺口仍须分别说明并实际影响定性判断、核验优先级或购买状态，不能因不计总分而隐藏负面。

- 安全合规先按具体风险和适用要求判断，再形成通过/待核/不满足的独立门槛；缺公开整份报告不自动使整款待核。已证实不符合关键食品安全要求的候选不得因便宜、营养参数好或推荐分高而保留为可买结论。质量分结合标示与实测一致性、配料/营养质量、批次稳定性、储存及可靠反馈，不因符合底线再奖励一次安全分。
- 营养目标适配、蛋白单位费用和检测可靠性分别归适配、价值和质量；同一理由只进入一个主要评分项。不给“蛋白越高越好”“配料越少越好”或“进口更好”的通用分。
- 支持质量评分的关键资料不足时保留对应实证质量分N/A，指出缺哪项、受影响维度及为何影响判断；不因缺一份公开报告抹去其他已核证据。有意义的主观推荐分标暂定和条件。关键健康/生命风险的符合证据或法定必备要求的满足情况实质未明时，说明具体危害、缺失证据及现有替代证据为何不足，不写可以直接下单的确定结论；其他未核项目按范围披露。污染物、微生物、过敏原和储运等适用安全底线不能因报告不公开或营养表现好而降低。
- 每款聊天的“质量与可靠性”“安全与合规”“需求适配”分别写出已核的关键数据和判断；具体审查表、原始规范和检测报告可附后。12项说明均保留；一般商品的七项原权重及前置商城/红包格式不变，助农产品的标题、交易/信息入口及定性结论按专项适配。
- 研究结束明确哪些审查已完成、哪些只核到标签、哪些仍缺报告；不能把“建立了审查规则”或“列出检查表”写成已完成某款食品的安全与营养审查。
